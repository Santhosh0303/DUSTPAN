# Dustpan

> **Static analysis for Power BI estates — find duplicate, unused, and drifting measures without pretending uncertainty is certainty.**

Dustpan scans Power BI Project (`.pbip`) trees and related semantic/report definitions. It is deliberately conservative: **a false positive is worse than a false negative**.

This repository contains Dustpan 0.1.2 source. The full README from the source package is committed in the following baseline commit.
